# 🏊‍♀️🚴🏃 Triathlon Data Analytics

Data-gedreven analyses van multi-sport trainingen en raceresultaten op basis van ruwe `.fit`-bestanden.

## 📁 Projectstructuur

- `triathlon_analyses/`: Notebooks met specifieke race- en trainingsanalyses.
- `utils/`: Herbruikbare functies (`triathlon_utils.py`) en instellingen (`config.py`).
- `output/`: Gegenereerde visualisaties en grafieken.
- `fit_bestanden/`: Invoermap voor `.fit`-databestanden.

## 🛠️ Gebruik

1. Plaats je `.fit`-bestand in de map `fit_bestanden/`.
2. Pas eventuele drempelwaarden aan in `utils/config.py`.
3. Run het notebook in `triathlon_analyses/`.
